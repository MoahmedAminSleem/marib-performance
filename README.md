# لوحة أداء مصنع مأرب — النسخة الأونلاين

تطبيق Next.js + PostgreSQL (Neon) — نفس لوحة الأداء بتاعتها بالظبط،
بس الداتا على سيرفر والشركة كلها بتشوفها من دومين واحد.

## سير العمل والذاكرة الكاملة
`سير-العمل.html` — الملف ده هو ذاكرة المشروع: القصة والمعمارية
وطريقة الحساب والمنطق وتاريخ الجولات وآخر اللي اتعمل.
بيتحدّث بعد كل جولة — **ابدأ من هنا في أي جلسة جديدة.**

## التشغيل (مرة واحدة — ١٥ دقيقة)
الدليل الكامل خطوة بخطوة بالصور جنب الملف ده (دليل-النشر.html).
الزتونة:
1. ارفع الملفات دي على مستودع GitHub خاص
2. اعمل قاعدة Neon وانسخ رابط الاتصال
3. استورد المستودع في Vercel + رابط الاتصال في DATABASE_URL → Deploy

أول حد يفتح الموقع: الجداول + حساب الأدمن + شهور يوليو/أغسطس/سبتمبر
+ الـ 2005 موظف بتوع الاتزان بيتزرعوا تلقائي من ملف الـ seed.

## ملفات مهمة
- `سير-العمل.html` — ذاكرة المشروع: الـ Workflow والحسابات وسجل الجولات
- `شرح-رسومات-رئيسية-المدير.html` — شرح حسبة الرسومات الستة في رئيسية المدير (معادلات + مصادر + أمثلة)
- `src/lib/bootstrap.ts` — إنشاء الجداول + البيانات الأولية (تلقائي)
- `public/app/` — تطبيق اللوحة نفسه (الثيم + الحسابات + الرسومات)
- `public/app/app_manpower.js` + `src/app/api/manpower/route.ts` — نظام الاتزان (الهيراركي + الأرشيف)
- `prisma/schema.postgres.prisma` — شكل قاعدة البيانات
- `الملفات-المتغيرة.txt` — ملفات آخر جولة (الجولة 41)
- `src/app/api/manpower/export/route.ts` — تصدير الاتزان: بيفوت حقيقي (شيت Manpower) + الهيكل + الموظفين + الأرشيف · و?template=1 بينزّل تيمبلت الرفع (Database + تعليمات + عمود حذف؟)
- `src/lib/marib/xlsx-writer.ts` — مولّد Excel الداخلي (بدون أي مكتبات خارجية — ده اللي حل مشكلة exceljs وبناء Vercel)

## تعديلات مستقبلية
اطلب التعديل من المساعد → هيسلّمك ZIP فيه الملفات المتغيرة بس →
ارفعها على GitHub (Add file → Upload files) → Vercel ينشر التعديل لوحده في دقيقة.
وبعد كل جولة، `سير-العمل.html` بياخد بلوك جديد في سجل التحديثات بتاعه.
