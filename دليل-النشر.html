ارفع الكود على GitHub github.com

~٥ دقايق — أول مرة في حياتك تتعمل عادي
  1. افتح github.com واعمل حساب (زرار Sign up — زي أي إيميل جديد).
  2. من فوق شمال اضغط + ← New repository.
  3. في خانة Repository name اكتب: marib-performance — واختار Private (مهم — الكود يفضل مخصوص عليك) — بعدين Create repository.
  4. هتلاقي صفحة فيها uploading an existing file — اضغط عليها.
  5. افتح ملف الـ ZIP اللي معاك (marib-performance-deploy.zip) وفكّه على جهازك.
  6. اسحب كل محتويات المجلد اللي اتفك (٤١ ملف/مجلد — مش المجلد نفسه) على صندوق السحب في GitHub. استنى لحد ما أسماء الملفات تخلص رفع (شريط بيجن فوق).
  7. اكتب في خانة التعليق: first deploy واضغط Commit changes.
ليه Private؟ عشان محدش غيرك يشوف كود الموقع. Vercel هيقرأه عادي برضه — ده مسموح.
٢

اعمل قاعدة البيانات المجانية neon.tech

~٣ دقايق — هنسخ منها سطر واحد بس
  1. افتح neon.tech واعمل حساب (تقدر تضغط Sign up with GitHub بنفس حسابك).
  2. اضغط Create project (لو سألك عن اسم: marib — والمنطقة: Frankfurt أو أقرب واحدة).
  3. بعد ما يخلص، هتظهرلك صفحة فيها Connection String — سطر طويل بيبدأ بـ postgresql://. اضغط زرار النسخ (Copy) جنب السطر ده واحتفظ بيه في ملف نصي مؤقتًا.
postgresql://neondb:XXXXXXXX@ep-xxxx-xxxx.region.aws.neon.tech/neondb?sslmode=require
السطر ده هو مفتاح الداتا كلها — ميبعتش لأي حد ولا بيتكتب في أي شات. اللي هيحصله نسخة واحدة بس بنحطها في Vercel في الخطوة الجاية.
لو ضاع منك السطر في أي وقت: ادخل على Neon ← مشروعك ← Dashboard ← هتلاقيه هناك بنفس المكان. ولو حسيت يومًا إنه اتسرب: من Reset password بتعمل مفتاح جديد في ثواني.
٣

انشر الموقع vercel.com — هنا بيجي الدومين

~٥ دقايق منها دقيقة واحدة بتعمل حاجة، والباقي السيرفر بيشتغل لوحده
  1. افتح vercel.com واضغط Continue with GitHub (بنفس حساب GitHub).
  2. من صفحة Projects اضغط Add New... ← Project.
  3. هتلاقي مستودع marib-performance في القائمة — اضغط Import جنبه.
  4. قبل ما تدوس Deploy — انزل لخانة Environment Variables:
    KeyValue
    DATABASE_URLالصق هنا سطر postgresql://... اللي نسخته من Neon
    خلي Environments التلاتة (Production / Preview / Development) متعلمة زي ما هي.
  5. اضغط Deploy واستنى من دقيقة لـ ٣ دقايق — هتشوف شريط أخضر Congratulations!.
  6. اضغط Continue to Dashboard — فوق هتلاقي رابط موقعك، شكله كده:
https://marib-performance-xxxx.vercel.app
الدومين ده ببلاش وباسم موقعك — ابعت لأي حد في الشركة يفتحه ويسجل دخول. يدخل مرة واحدة على جهازه ويفضل فاكره. (لو عايز تختبر: افتحه من موبايلك بـ 4G مش الواي فاي بتاع المكتب.)
أول مرة تفتح الموقع ممكن تأخذ ١٠-٢٠ ثانية (السيرفر بيصحى وبيعمل الجداول + بيحط شهور يوليو/أغسطس/سبتمبر تلقائي). بعدها بيفتح بسرعة عادية.

أول دخول — وقفل الباب

~دقيقتين
  1. افتح الدومين — هتلاقي شاشة الدخول بتاعة الجينز (نفس اللي انت متعود عليها).
  2. سجّل: Amin / 2872002 — وعلامة "تذكرني" لو جهازك الشخصي.
  3. فورًا: من القايمة الجانبية ← المستخدمين ← دور على حسابك ← زرار المفتاح ← باسورد جديد قوي (حروف + أرقام + رمز، مش أرقام موبايلك ولا اسم الشركة). من اللحظة دي انت اللي معاك مفتاح الشقة.
  4. ضيف حسابات الزملاء: اسم + باسورد مؤقت لكل واحد — وعلّم جنب اسمه مفتاح "مسموح له يرفع الشهور" لو هو اللي هيرفع الإكسل — الباقي كله مشاهدة. (الباسورد المؤقت قوله يغيره من نفس المكان أو غيّره أنت له.)
  5. الشهور الثلاثة (يوليو ٧٣,٦٨٩ / أغسطس ١٣٦,٤٧٢ / سبتمبر ٢٠,٦٠٢) موجودة من أول لحظة — بدّل بينهم من قايمة "الشهر" فوق.
الشهر الجديد (أكتوبر): لما يجي — حد عنده صلاحية الرفع يضغط "البيانات" ← يختار ملف/مجلد الإكسل بتاع أكتوبر — بيترفع على السيرفر وكل الشركة تلاقيه على طول من قايمة الشهر.
؟

أسئلة بتتحصل كتير

عايز أعدّل حاجة في الموقع — أعمل إيه؟

قول للمساعد بتاعك ("عدّل كذا") — هيقولك: افتح الملف الفلاني في GitHub (زرار القلم ✏️ جنب اسم الملف)، عدّل السطر ده، اضغط Commit. Vercel ينشر التعديل لوحده خلال دقيقة من غير ما تلمس أي حاجة تانية. ده بالظبط معنى "تحت إيدك".

الشركة عايزة دومين باسمها زي marib.com؟

لما الإدارة توافق: اشترِ دومين من Namecheap أو GoDaddy (~١٠$ في السنة) واربطه من Vercel ← Project ← Settings ← Domains ← Add. الدليل بيساعدك لوحته لو احتجت. والنسخة المجانية بتستمر شغالة زي ما هي.

النت قطع في المصنع؟

من القايمة الجانبية زرار "أوفلاين" — بينزّل نفس الملف اللي بنشتغل بيه دلوقتي (شغال من غير نت بنفس الأرقام). النسختين ورا بعض زي ما اتفقنا.

حد نسا باسورده؟

انت (الأدمن) من المستخدمين ← زرار المفتاح جنبه ← باسورد جديد. لو انت نسيت باسورد الأدمن نفسه: قول للمساعد — فيه حل جاهز (أمر واحد بيرجّع باسورد مؤقت وانت تغيّره).

الموقع بيفتح ببطء أول مرة في اليوم؟

عادي — الخطة المجانية بتخلي السيرفر "ينام" لو محدش فتح الموقع ساعة-تلاتة، وأول زائر بيصحّيه (١٠ ثواني تقريبًا). طالما الشركة بتفتحه كل يوم، مش هتحس بيها أصلًا.

داتاي فين بالظبط؟ وحد يقدر ياخدها؟

على سيرفرات Neon (قاعدة PostgreSQL) — مرمّزة أثناء النقل (HTTPS) والباسوردات متخزنة متشفرة جوا السيرفر نفسه. مفتاح القاعدة موجود في مكان واحد بس (Vercel) ومش في الكود. أقوى نقطتين تبقى عندك: باسورد أدمن قوي + ماتشاركش الحساب بتاعك.

ظهرلي خطأ في صفحة الـ Deploy؟

٩٠٪ من الحالات: نسيت تحط DATABASE_URL أو نسخته ناقص. روح Vercel ← Project ← Settings ← Environment Variables ← اتأكد إن السطر موجود وكامل ← بعدين Deployments ← آخر صف ← النقط التلاتة ← Redeploy. لو استمر: افتح الدومين على /api/health وابعت اللي مكتوب للمساعد.
