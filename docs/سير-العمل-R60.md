### 2) فلسفة الإصلاح: حارس حقيقي مش تعصيب

العلم بيقول إن أي قراءة `arr[i]` نوعها `T | undefined` — حتى لو الحدود
مضمونة. النمط السائد في الكود كان:

```ts
const cur = await q("… LIMIT 1", [id]);
if (!cur.length) return fail("none", 404);   /* فحص الطول */
const old = cur[0];                            /* TS: ممكن undefined */
```

الإصلاح المعتمد في كل المواقع: **الحارس على العنصر نفسه** — نفس
السلوك بالظبط (صف فاضي ⇔ عنصر undefined) لكن الـ narrow حقيقي:

```ts
const old = cur[0];         /* R60: حارس العنصر بدل فحص الطول */
if (!old) return fail("none", 404);
```

ده مش تجميل: قبل R60 لو حد زوّد شرط بعد كدا زي `if (!cur[0].vac)` كان
ممكن يضرب undefined في الإنتاج لو الراجع فاضي — النوع كان بيكدب. دلوقتي
النوع بيقول الحقيقة والكومبايلر بيمسكها.

| الملف | المواقع | النمط |
|---|---|---|
| `api/manpower/route.ts` | 9 مواضع (editMany/delMany/edit/del/fill/vacDel/deptRename/deptMove/deptDelete) | `const old = cur[0]; if (!old) …` — كل استخدامات `cur[0].x` بقت `old.x` |
| `api/po/route.ts` | تفاصيل PO الواحد | `po0 = rec[0]` + `t0 = totals[0]` + `?.` مع `?? 0` للـ aggregate (بيرجع صف واحد دايمًا) |
| `lib/marib/entries.ts` | matchEmployee ×2 | `const e0 = er[0]; if (e0) …` |
| `api/audit/route.ts` | مُنشئ الكيانات | `map` بقت `flatMap` + حارس `if (!creator) return []` (المجموعة بتتعمل عند أول حدث فأول عنصر مضمون — الحارس للـ checker) |
| `api/data/route.ts` | مزامنة الشهور | `const row = s.r[i]; if (!row) continue;` |
| `lib/marib/session.ts` | currentUser | `const r0 = rows[0]; if (!r0) return null;` |

**الـ `!` الوحيدة في الجولة:** فهرس جدول CRC المقنّع بـ `& 0xff`
(0..255) في جدول طوله 256 — مبررة رياضيًا في تعليق داخل الكود، مش
تعصيب عمياء.

## إيه الفايدة الفعلية للمالك

1. **باقات الفهرس الناقص بقت مستحيلة:** أي `rows[0].field` من غير حارس
   بتتقص في الـ CI/البناء مش في الإنتاج قدام المستخدم.
2. **المراجعات بقت أسرع:** الفرق الجاي في مسارات الـ API الكومبايلر
   بيمسك فيه قراءة عنصر مش محروسة قبل ما الكود يشوف النور.
3. **الحارس أصبح من النوع مش من الذاكرة:** مفيش «افتكرت أفحص الطول؟» —
   النوع بيفرض الفحص.

## دروس الجولة

- `arr.length` **مش بتنرّف** `arr[0]` — دي أشهر فخ في العلم؛ الحارس على
  العنصر هو الـ idiom الصحيح وأرخص تغيير ممكن (سطرين).
- التقديرات القديمة («~30+») بتتضخم: القياس الفعلي 76 — اقيس قبل ما
  تخطط.
- الأعلام المجانية (0 خطأ) هدية ببلاش — والتكلفة 461 لازم تتوثق سبب
  الرفض عشان محدش يفتحها من جديد من غير دليل.
- `for (const x of typedArray)` بيشيل فئة كاملة من أخطاء الفهرس من غير
  أي `!`.
