# سير العمل — الجولة 66

**سطح العمل:** الصفحة الرئيسية (الخلفية المصورة + العنوان) · صفر API.

## الخلاصة في سطر

**ملاحظات المالك الثلاثة على الرئيسية اتنفذت:** كلمة JACK&JONES
الكبيرة اتشالت من الخلفية العلوية (كانت مكررة)، وجملة «إيه اللي
هتشغّله النهارده؟» + الخط الأصفر المتقطع تحتها اتشالوا، ولوجو SET
الغلط اتبدل بلوجو **STING** — البراند التركي (1985) — بنفس أسلوب
صف البراندات. E2E **66/66**.

## طلب المالك (حرفيًا)

> «كامة jack&jones اللي في الخلفية فوق اللي معلملك عليها بالاحمر دي
> انا مش عايزها كفاية هي مكتوبة مرة وسط البراندات. وكمان جملة
> "ايه اللي هتشغله النهاردة؟" مش عايزه وهتلاقيني معلملك عليها
> بالاحمر شيلها هي والخط الاصفر اللي تحته. وهتلاقي ورا كلمة "اي
> اللي هتشغله النهاردة" لوجو براند Sting التركي ولكن للاسف مكتوب
> "SET" ودا مش لوجو البراند البراند التركي اللي اسمه Sting وبيبيع
> بناطيل جينز ... هو دا اللي عايزك تدور عليه وتضيفه بانسيابيه بدل
> الكلمة واللوجو الغلط SET دا.»

## 0) التحقق من البراند أولًا

قبل أي بكسل: بحث ويب أكد إن **STING براند رجالي تركي من 1985**
(سفراؤه عبر السنين فابيو كانافارو وباتيستوتا — مصدر opmar.com.tr،
متجر Oopmar التركي). لوجوه وورد-مارك بأحرف كبيرة عريضة — فالاستبدال
بـ «STING» بنفس أسلوب صف البراندات هو التمثيل الصح للبراند، وبيحقق
«بانسيابية» المطلوبة لأن كل لوجوهات الصف أصلًا سادة بنغمة على نغمة.

## 1) الاكتشاف البرمجي (قبل اللمس)

إحداثيات VLM وحدها طلعت **متقلبة وبتضلل** (3 قراءات = 3 خرائط
مختلفة لصف البراندات). الحسم بالتحليل البرمجي للبكسلات:

| العنصر | الإحداثيات المكتشفة | الطريقة |
|---|---|---|
| كلمة JACK&JONES الكبيرة | حروف x=528-903 / y=94-140 | بروفايل صفوف+أعمدة للداكن (<80) |
| حروف SET (S·E·T + شريط رأسي) | x=728-864 / y≈216-260 | انحراف عن وسيط الخلفية المحلية |
| الجيران للمقاسنة والنغمة | ONLY 556-659 · RDD 873-963 · GARCIA 361-492 | نفس الطريقة |
| صف البراندات (النهائي بعد الفصل) | y≈214-262 | بروفايل مستقل عن نطاق الكلمة الكبيرة |

**الدرس المكرر:** أول قراءة VLM لصف البراندات كانت مزحزحة براند
كامل (قال SET مكان ONLY) — القصّة المركّزة بالتكبير + مطابقة
التكتلات الداكنة = التثبيت الصح.

## 2) الكلمة الكبيرة اتمسحت (inpaint حتمي)

قناع = البكسلات الداكنة (<135) **والفاتحة (>232)** جوه نطاق الكلمة
(بتشمل لمبات الحروف) → اتساع 9 بكسل (يغطي الحواف الناعمة) → ريشة
Gaussian زي R65 → `cv2.inpaint` TELEA r=9. الدنيم بين الحروف
فضل أصلي — التعديل مس الحروف بس. الفحص: **min=123** في منطقة
الحروف القديمة (كان فيها سواد شبه صفر).

## 3) SET → STING (استبدال بنفس نغمة الصف)

- **التنظيف:** قناع انحراف ±16 عن وسيط الخلفية المحلية + اتساع 9
  + ريشة → TELEA r=7. راح معاه الشريط الرأسي اللي كان جنب الـ T.
- **الرسم:** «STING» بخط Liberation Sans Bold (وورد-مارك عريض)،
  cap-height 34px (بين ONLY 26 و GARCIA 32)، لون مسحوب من نغمة
  حروف الجيران (شبه أسود BGR≈66,60,53)، ألفا 210/255 + بلور
  Gaussian 0.9 — الحروف بتحس إنها **مطبوعة على النسيج** مش لاصقة.
- **المكان:** متمركزة على مركز السلوت الفاضي (بين ONLY وRDD) —
  مش ملتصقة بأي جار.
- **التحقق:** قراءة VLM مباشرة على قصّة 4x: «يقول STING وبيندمج
  طبيعيًا» + قراءة الصف كاملًا: «JACK&JONES, GARCIA, ONLY, STING,
  RDD, VOICE» بالترتيب الصح.

## 4) الجملة + الخط الأصفر اتشالوا (الكود)

| الملف | التعديل |
|---|---|
| `src/app/skeleton.ts` | `<h2 id="mgTitle">` بقى `hidden` افتراضيًا (بدون data-i18n) |
| `public/app/app_auth.js` | `tt.hidden = !none` — العنوان بيظهر **بس** لما مفيش أي سطح مسموح، وساعتها بيقول `perm_none` (الحالة الوحيدة اللي ليها لازمة) |
| `public/app/app.css` | `border-bottom:2px dashed rgba(217,168,107,.35)` + `padding-bottom` اتشالوا من `.mg-in h2` + الثيم الفاتح |
| `public/app/i18n_dict.js` | مفتاح `mg_title` اتمسح بالكامل (ar/en/tr) — `mg_hello` («أهلًا بيك يا فلان») فاتل زي ما هو |

**قرار تصميمي:** إمساك العنصر `#mgTitle` في الـ DOM بدل مسحه نهائيًا
— عشان رسالة «مفيش أي شاشات متاحة» لحساب من غير صلاحيات تفضل
موجودة (بدون خط تحتي) من غير ما أي يوزر طبيعي يشوف أي حاجة.

## 5) الإلزاميات

- **Cache-bust:** `?v=r65` → `?v=r66` في 15 موضعًا (12 سكريبت في
  page.tsx + css في layout.tsx + الخلفية واللوجو في skeleton.ts) —
  **مهم جدًا للخلفية:** بدونه المتصفح هيفضل يعرض الصورة القديمة
  اللي فيها SET والكلمة الكبيرة.
- **E2E_V** في `e2e_lib.sh` اتحدث لـ r66.
- **CODE-MAP** اتعاد تولدته مرتين (المرة التانية بعد إضافة
  `e2e_r66.sh` نفسه — فحص الطزاجة بيشمل ملفات السكريبتات).

## 6) الإثبات (E2E — 66/66)

- التشغيلة الأولى: 65/66 — الفشل الوحيد كان CODE-MAP قديمة (اتولدت
  قبل إنشاء سكريبت الجولة نفسه) — اتعاد التوليد والتشغيلة الثانية
  **66/66 EXIT=0**.
- **الحرسان الجديدة الدائمة في الـ E2E:**
  1. منطقة الكلمة الكبيرة القديمة (y90-146/x520-912): `min>100` —
     ميرجعش أبدًا.
  2. لوجو STING موجود: >400 بكسل داكن في سلوتة + **4+ تكتلات
     حروف** (عمليًا 5: S·T·I·N·G) — لو البلور أو الألفا باظت
     والكلمة ذابت، الفحص بيمسكها.
  3. الخط الأصفر المتقطع **غايب** من الـ CSS المتخدم.
  4. `mg_title` **غايب** من القاموس + `mgTitle` مخفي في المتصفح
     بعد دخول حساب عنده صلاحيات.
  5. المربع الأسود القديم (حارس R65) لسه شغال.
- **صفر تغيير سلوك:** 11 JSON + 5 XLSX بالبايت + 14 مفتاح صلاحيات.
- فحص بصري VLM للقطة النهائية: مفيش كلمة كبيرة، مفيش عنوان بخط
  أصفر، اللوجو فوق يمين كبير، الشكل نضيف.
