## اللي اتعمل

### R51-1 — إصلاح u2039 + مشكلة الصلاحيات
- `\\u2039` → `‹` في زرار الصلاحيات (skeleton.ts) + مسافة ناقصة اتضافت
  (كان لازق في الكلمة).
- **حالة الصلاحيات الفاضية اتعاد تصميمها** من رسالة ميتة لبطاقة مفيدة:
  أيقونة + «لسه مفيش مستخدمين تانيين» + شرح إيه وظيفة الصفحة + شرائح
  الأدوار التلاتة (المطوّر/أدمن/مستخدم) بألوانهم + **زرار «＋ إضافة مستخدم»
  بيفتح نافذة المستخدمين فورًا** (MaribAuth.openUsers).
- 3 مفاتيح i18n جداد (pm_empty_t / pm_empty_d / pm_add_user) عربي/إنجليزي/تركي.

### R51-2 — الثيمات في مربعات
- CSS الثيمات المفقود اتكتب من جديد (طبقة R51): كل ثيم بقى **مربع 108×108
  مقسوم 4 أرباع ملونة** (الخلفية/الذهبي/السطح/الأخضر) + الاسم تحته +
  **علامة ✓ خضراء دايرة على الثيم النشط** + إطار أخضر حوالين المختار.
- أكواد الـ hex النصية اتشالت من العرض (المربعات هي المعيار البصري).
- دعم الثيم الفاتح كامل (`[data-theme="light"]` overrides).

### R51-3 — أيقونات بروفيشنال (مكان رسومات الـ AI)
- **Fluent 3D Emoji** (مايكروسوفت، MIT) — نفس الإستhetic المرموق اللي
  بيتدور عليه الناس في Pinterest: ناعمة، متسقة 100%، خلفية شفافة.
- 9 أيقونات اتنزّلت من مصدر مايكروسوفت الرسمي واتكمّنت (256 لون + ألفا)
  → **21.3 KB بس للمجموعة كلها** في `public/app/icons/`.
- البوابة: 📊→**bar-chart** · 🧵→**balance-scale** (الاتزان!) ·
  📝→**clipboard** في البطاقات + gear/users/card-file-box/door في الأدوات.
- صفحة الدخول: **اللوجو الأحمر القديم → أيقونة مصنع 3D** على بلاطة كريمية
  نظيفة (نفس اللوجو في التوب بار) + **الرسومات المرسومة اتشالت**
  (ماكينة الخياطة + البكرة + الخيوط المتقطعة) — اتحتفظ بالجيب والهوية
  الدنيم والجلو.
- كل أيقونة `img.ic3d` بظل ناعم drop-shadow وترند صح في الداكن والفاتح.

### R51-4 — الأربعة مربعات + التثبيت في كل الصفحات
- **هيدر الاتزان:** الأربعة أزرار (⚙ إعدادات / 👥 مستخدمين / 🗄 بيانات /
  🚪 خروج) بقوا **مربعات 44×44** بالأيقونات 3D (بدل SVG اللي مات) +
  زرار الصفحة الرئيسية بأيقونة البيت + الليبل.
- **توب بار تحليل الأداء:** اتضاف نفس الأربعة (tbDataBtn + tbLogoutBtn
  جداد + tbSetBtn/tbUsersBtn بقوا مربعات 40×40) — **نفس الأزرار في
  البوابة والداشبورد والاتزان = مثبتين في كل الصفحات** زي ما طلب المالك.
- الربط: زرار البيانات بيفتح بوب-أب البيانات (openDataPop) + الخروج
  متسجل في مصفوفة اللوج-أوت + زرار المستخدمين لسه أدمن-بس.
- الحجم موحّد: 40×40 في التوب بار، 44×44 في الاتزان، tooltips بالعربي.

### بنية التعديل
- skeleton.ts بـ **17 تعديل regex** (سكريبت `scripts/r51-edit-skeleton.py`)
  مع دالة `esc()` اللي بتهرب الاقتباسات **والأسطر الجديدة** (السلسلة سطر
  واحد — أول تشغيلة كسرت الـ TS string بـ newlines حقيقية واتصلحت فورًا).
- طبقة CSS R51 كاملة في آخر app.css (5.5KB) — بدون لمس أي قاعدة قائمة.
- cache-bust: `?v=r50` → `?v=r51` (app.css + 9 سكريبتات).
