## دورة الجولة السريعة (6 خطوات — دقيقة تحديد، دقائق تنفيذ)

```
0. الخطوة صفر: ls -lt /home/z/my-project/uploads/
   — مرفقات المالك الجديدة؟ VLM عليها الأول (البروتوكول تحت)
1. حدّد الملف من CODE-MAP.md (مش بتحتاج تقرأ الكود كله)
   + جدول «العرضة→الملف» تحت بيديك الملف على طول في مشاكل الواجهة
2. اقفل السيرفر لو شغال: pkill -9 -f "next" · عدّل الشريحة بس
3. tsc: bun run typecheck (أو npx tsc --noEmit)
4. bash scripts/e2e_rNN.sh  (انسخ سكريبت آخر جولة وعدّل الجزء الجديد بس)
5. bun scripts/code_map.mjs · حدّث 00/05/06 + سير-العمل-RNN · commit+push
```

**قاعدة الكفاءة:** سكريبت E2E الجديد = نسخة من اللي قبله (كل
الرجرسون بيتمسك لوحده) + فحوصات الجولة الجديدة بس. مفيش كتابة
من الصفر — ده اللي مخلّي الجولة تبقى دقايق.

## بروتوكول مرفقات المالك (محلول نهائيًا في R71 — القناة الأساسية: صفحة /up)

**القناة الأساسية (R71):** صفحة رفع ثابتة جوّه الأب نفسه — اللينك
مش بيتحدث خالص (ده كان شرط المالك الصريح بعد ما رفض share-link
اللي بيتجدد مع كل محادثة):

```
لينك-المعاينة/up?k=2872002     ← المالك يفتحه مرة ويبوكماركه
```

- المالك بيسحب أي صورة/ملف على المنطقة أو **Ctrl+V للّصق** —
  والبايتس بتوصل فعلًا `/home/z/my-project/uploads/` (طابع زمني
  قدام الاسم) والصفحة بتعرض إيصال «✓ وصلت» + قائمة بكل اللي وصل.
- **الوكيل (أي جلسة):** الخطوة صفر فوق — `ls -lt uploads/` →
  `z-ai vision -p "..." -i <الملف>` على أي ملف جديد.
- الامتدادات المسموحة: صور/PDF/نصوص/log/json/csv/فيديو/zip —
  لحد 30MB. بدون مفتاح = 401.
- درس تقني (لو هتتعديل على الصفحة): كائن File الجاي من الإنبوت
  بيتسلسل فاضي في جسم fetch في المتصفحات الـ headless — الصفحة
  بتقرا البايتس (`arrayBuffer`) وتبني ملف جديد قبل الإرسال.
  **متشيلش الجزء ده** — رحلة الرفع في الـ e2e بتعتمد عليه.

**Fallback (لسحب صور قديمة من محادثة متشاركة):**
`scripts/fetch_chat_images.sh` شغال ومختبر (4/4 صور سليمة):
```
bash /home/z/my-project/scripts/fetch_chat_images.sh "<share_url>" [outdir]
```
بيفتح صفحة المشاركة في متصفح headless ويسحب URLs الصور من الـ DOM
ويحملها من الـ CDN الموقّع. دروسه التقنية (timeout حوالين eval ·
استخراج قبل السكرول بسبب virtualization · JSON مزدوج) فوق في تاريخ
الجولات — بس مش مسار المالك اليومي خالص دلوقتي.

## قواعد السرعة (المفعّلة من R70)

- الفحص بيقيس **بالظبط** اللي اشتكى منه المالك (حواف الشاشة نفسها
  مثلًا — مش جوه الحاوية) — عشان مايتكررش «الإصلاح عدّى والشكوى
  فضلت».
- أي قيمة layout بتختلف بين الثيمات → تتقاس من DOM الحي (درس R69).
- أي حالة `.on` جديدة → تتحقق في الثيمين من أول يوم (درس R69).
- لقطة before لكل عرضة قبل الإصلاح — «الباج لازم يشوف قبل ما يصلّح».
- بعد تعديل كود في dev: اختبار المتصفح لازم يتم بعد navigate كاملة +
  انتظار — `location.reload()` ممكن يجيب كود قديم لو سبق الـ recompile
  (درس R71: الإصلاح كان سليم والاختبار بيجري على كود قديم).
