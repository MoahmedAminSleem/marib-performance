## دورة الجولة السريعة (5 خطوات — دقيقة تحديد، دقائق تنفيذ)

```
1. حدّد الملف من CODE-MAP.md (مش بتحتاج تقرأ الكود كله)
   + جدول «العرضة→الملف» تحت بيديك الملف على طول في مشاكل الواجهة
2. اقفل السيرفر لو شغال: pkill -9 -f "next" · عدّل الشريحة بس
3. tsc: bun run typecheck (أو npx tsc --noEmit)
4. bash scripts/e2e_rNN.sh  (انسخ سكريبت آخر جولة وعدّل الجزء الجديد بس)
5. bun scripts/code_map.mjs · حدّث 00/05/06 + سير-العمل-RNN · commit+push
```

**قاعدة الكفاءة:** سكريبت E2E الجديد = نسخة من اللي قبله (كل
الرجرسون بيتمسك لوحده) + فحوصات الجولة الجديدة بس. مفيش كتابة
من الصفر — ده اللي مخلّي الجولة تبقى دقايق.

## بروتوكول صور المالك (محلول في R70 — الأداة شغالة ومختبرة)

**القياس الفعلي:** لقطات الـ IM بتوصل للسandbox **اسم بس مش بايتس**
(اتأكدنا بالبحث الكامل + كل مسارات chat.z.ai المباشرة → SPA/404).
**بس الصور نفسها بتتخزن على CDN المنصة** وتتعرض في صفحة المحادثة
بـ URLs موقعة (`z-cdn-media.chatglm.cn/files/{uuid}?auth_key=...`)
بتتولد fresh مع كل فتح صفحة — والتحميل منها بـ curl شغال بدون كوكيز.

**الحل المختبر (end-to-end):** `scripts/fetch_chat_images.sh`:
```
bash /home/z/my-project/scripts/fetch_chat_images.sh "<share_url>" [outdir]
```
بيفتح صفحة المشاركة في متصفح headless → يسحب كل URLs الصور من
الـ DOM → يحملها ويتأكد من الماجيك بايتس. اتاختبر على رابط المحادثة
القديمة المشتركة: 4/4 صور نزلت سليمة (1MB + 332KB + 55KB + 47KB).

**اللي محتاجه من المالك (مرة واحدة لكل محادثة):**
1. من المحادثة: **Share → Create link** (زرار المشاركة)
2. يبعت اللينك هنا في الشات
3. من ساعتها كل صور المحادثة (القديمة والجديدة) بتتسحب بالأداة
   — مش لازم يرفع حاجة على GitHub خالص.

**درس تقني مهم (عشان الأداة متتكسرش):** 
- `--timeout` flag بيكسر `agent-browser eval` («Operation timed out») —
  الحماية من الهنج بتتعمل بـ `timeout` بتاع bash حوالين الأمر مش flag
- صفحة المحادثة virtualized: السكرول بيشيل الصور اللي عدّت من
  الشاشة → الاستخراج بيحصل **قبل** السكرول + بيتجمع بعد كل سكرولة
- الـ CLI بيرجّع ناتج eval الـ JSON **مزدوج التشفير** → فك مرتين
  بـ python

**لو الرسمة نفسها مهمة فورًا** والمالك مش عايز يعمل Share: نفس مسار
الريبو (سحب وإفلات على GitHub) أو لينك صورة مباشر — بس المسار الأساسي
هو الـ Share.
