## دورة الجولة السريعة (5 خطوات — دقيقة تحديد، دقائق تنفيذ)

```
1. حدّد الملف من CODE-MAP.md (مش بتحتاج تقرأ الكود كله)
   + جدول «العرضة→الملف» تحت بيديك الملف على طول في مشاكل الواجهة
2. اقفل السيرفر لو شغال: pkill -9 -f "next" · عدّل الشريحة بس
3. tsc: bun run typecheck (أو npx tsc --noEmit)
4. bash scripts/e2e_rNN.sh  (انسخ سكريبت آخر جولة وعدّل الجزء الجديد بس)
5. bun scripts/code_map.mjs · حدّث 00/05/06 + سير-العمل-RNN · commit+push
```

**قاعدة الكفاءة:** سكريبت E2E الجديد = نسخة من اللي قبله (كل
الرجرسون بيتمسك لوحده) + فحوصات الجولة الجديدة بس. مفيش كتابة
من الصفر — ده اللي مخلّي الجولة تبقى دقايق.
