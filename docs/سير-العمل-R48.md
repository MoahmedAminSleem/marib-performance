# سير العمل — R48 (Refactoring)

**التاريخ:** 16 سبتمبر 2026 · **النوع:** تنظيف شامل بدون أي تغيير في السلوك الظاهر
**الطلب:** «اعمل refactoring»

> المبدأ المتبع: الـ refactoring الصح = نفس السلوك بالظبط، كود أقل،
> مسؤولية واحدة لكل حاجة، واختبار أقوى من اللي قبله. ممنوع نلمس
> package.json (قاعدة المالك) — فكل التنظيف من غير أي تغيير في الـ deps.

   الفرونت: manpower ×10 · entries ×10 · users ×7 · translate ×4 · auth ×4 ·
   settings ×2 · perms ×2 · data ×2 · storage ×1 · audit ×1.
   **مفيش ولا نداء واحد** على: auth/login · auth/me · auth/logout · months ·
   users/[id] — كلهم نظام Prisma القديم الميت.

## R48-2 — مسح نظام Prisma القديم بالكامل (نظام واحد: marib)

استخدام. اللي اتمسح:

**Routes (7 — كلها 404 دلوقتي):**

**Lib (3 ملفات — 324 سطر):**
- `src/lib/db.ts` (Prisma client) · `src/lib/auth.ts` (scrypt + sessions
  قديمة) · `src/lib/bootstrap.ts` (DDL قديم + زرع قديم)

**Seeds (293KB):** `src/server/seed/2026-0{7,8,9}.json` — بيانات شهور
النظام القديم (النظام الحي بيقرأ marib_data — والداتا على Neon في أمان،
مسح الكود مش بيمس الداتا).

لأن package.json ممنوع يتلمس، ومفيش أي كود بيستوردهم (بيتولّدوا بس
ومحدش بيفتحهم).

**فايدة أمنية:** الـ login القديم كان لسه شغال وقابل للنداء — دلوقتي
الباب ده مقفول تمامًا.
