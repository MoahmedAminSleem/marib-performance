## اللي اتعمل

### R52-1 — تقسيم app_main.js إلى 4 وحدات (4583 ← 2196+1444+611+393)

| الملف | السطور | المحتوى |
|-------|--------|---------|
| `app_main.js` | 4583 ← **2196** | النواة: الحالة + الأدوات + الفلاتر/URL + الدريو + الإعدادات + الأهداف + التشغيل + واجهة App |
| `app_pages.js` | **1444** (جديد) | عرض صفحات التحليل الثمانية + بيت المدير (Grafik) + multiLine |
| `app_entries.js` | **611** (جديد) | إدخال البيانات: الإنتاج/الغياب/الأوفر تايم + الكومبوبوكس |
| `app_admin.js` | **393** (جديد) | الإدارة: سجل التغييرات + التخزين + بيت المدير + الصلاحيات |

- **آلية الربط:** app_main بيبني `window.__maribCtx` (جسر بـ 50 رمز —
  نفس المراجع بالظبط، مفيش نسخ) والوحدات بتاخد رموزها منه وقت التحميل.
  ترتيب التحميل في page.tsx: core → pages → entries → admin → auth →
  manpower — كله قبل أي تشغيل (auth هو اللي بيبدأ البوت).
- **التحليل قبل القطع:** 5 سكريبتات اعتماديات (سطر-بسطر عبر Python)
  حددت خطوط القطع النضيفة: صفحات العرض محتاجة 17 رمز بس من النواة،
  الإدخال 8، الإدارة 12 — والعكس (النواة → الوحدات) كله وقت-تشغيل
  مش وقت-تحميل. صفر إعادة إسناد للمتغيرات المشتركة (state/TH) = المرور
  بالمرجع آمن.
- **الباجين اللي طلعوا واتصلحوا في الـ E2E:**
  1. `TV/TS/TB` (مساعدو عناوين i18n) — تعريف multi-var في سطر واحد
     (`var T=..., TP=..., TV=...`) كان بيطلع أول اسم بس في التحليل الأولي.
     اتضافوا للجسر وللـ destructure بتاع الوحدات.
  2. **setAvPhoto طلعت مش ميتة** — `window.MaribMe.set` بيناديها (تحليل
     الـ enclosing-function ضلل لأن الندا جوه object-literal method).
     الحذف الأولي بلع MaribMe + DEF_TH + TG_FIELDS — كلهم اترجعوا حرفيًا
     من git، والتعليق الغريب اللي سرح لذيل app_entries اتشال.
- **الدرس المسجل:** أي مسح «كود ميت» لازم يتدقق يدويًا — النداات جوه
  object-literal methods (`obj: { set: fn }`) بتضلل تحليل الـ enclosing.

## الاختبار (الـ Loop كامل)

1. **تحليلات:** node --check ×4 + سكريبت تحقق مراجع (صفر رمز ناقص من
   الجسر) + tsc + build.
2. **API (35 فحص، سيرفر standalone):** كل السكريبتات 200 (بما فيها
   الملفات الثلاثة الجديدة) + الدخول + كل الـ APIs + **الاستيراد
   round-trip**: 40 موظف حقيقي كصفوف 18-عمود → استيراد → 0 inserted /
   40 updated / 770 removed (سلوك «الشيت هو الحقيقة» الصحيح للشيت الجزئي)
   → undo → **828 رجعوا كلهم**. ده إثبات إن manpower_io.ts حرفيًا زي القديم.
3. **متصفح (18 لقطة):** دخول + بوابة + **4 KPI + 9 رسومات في الرئيسية** +
   الـ 6 صفحات (أرقام المحتوى مطابقة بالبايت لما قبل التقسيم) + فورم
   الأوفر تايم بالكومبوبوكس (بحث «محمد» = 30 نتيجة) + الإعدادات بكل
   شاشاتها الستة + الثيمات (مربعات + تبديل فاتح) + TR/LTR + الاتزان
   (شجرة + بحث + 810 موظف) + **صفر أخطاء كونسول في الجلسة كلها**.

## ملاحظات تشغيلية

- البيانات ما اتلمستش في أي لحظة (الاستيراد الاختباري على نسخة الـ
  standalone وبـ undo فوري).

- أي جولة جاية بتعدل العرض → `app_pages.js`، الإدخال → `app_entries.js`،
  الإدارة → `app_admin.js`، المنطق المشترك/الحالة → `app_main.js`.
