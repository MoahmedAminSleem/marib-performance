## 🔴 المشاكل المعروفة

1. **dev server instability:** الحل: `pkill -9 -f "next"` ثم إعادة التشغيل.
2. **PGlite init:** أحياناً بتفشل. الحل: `rm -rf db/pglite` (الزرع بيرجع تلقائيًا).
3. **⚠️ PGlite multi-process:** ممنوع فتح PGlite instance تاني على نفس `db/pglite`
   والسيرفر شغال (سكريبتات الزرع المباشرة كده بتخرب الـ visibility). الاسترجاع
   من الـ API دايمًا أو وقّف السيرفر الأول. (الإنتاج Postgres/Neon — مش متأثر.)
4. **الترجمة في بيئة محلية معزولة:** Google gtx / MyMemory ممكن يردوا 429 من
   IP مشترك — على Vercel شغالين عادي.
