٢ارفع كل حاجة مرة واحدة — ٣ دقايق

افتح الريبو: github.com/MoahmedAminSleem/marib-performance

  • اضغط زرار Add file (الأخضر) → Upload files
  • اسحب من فولدر الـ ZIP المفكوك: فولدر public + فولدر src + الملفات الأربعة (سير-العمل.html · README.md · next.config.ts · الملفات-المتغيرة.txt)
  • GitHub هيقولك "modified" لكل ملف قديم و"added" لملف سير العمل الجديد — وده المطلوب بالظبط
  • انزل تحت → اكتب في خانة الرسالة: R29 - OT by line + workflow → Commit changes
بديل لو السحب مش راضي يشتغل على جهازك: ادخل جوه كل فولدر في GitHub على حدة (public/app/ ← الملفين · src/app/ ← skeleton.ts ← أصل الريبو ← الباقي) واعمل نفس الخطوات: Add file → Upload files → اسحب الملفات → Commit. نفس النتيجة بالظبط.
ملحوظة: رفع ملف ليه نفس الاسم والمسار بيكتب تلقائيًا فوق القديم — مفيش أي خطوة مسح إضافية.

  • بيكبر معاك: بعد كل جولة بنضيف بلوك جديد في آخره يقول عملنا إيه — فأول ما تفتحه تعرف آخر حاجة على طول
  • لو النسيجة ضربت: لو نسيت إحنا واصلين فين — أو رفعت الريبو لمساعد جديد — الملف ده بيرجّع كل السياق في قراءة واحدة
  • بعد ما ترفعه هيشتغل من جوه الريبو نفسه — افتحه من GitHub في أي وقت بتحميله وفتحه في المتصفح

؟أسئلة هتجول في دماغك

الداتا واليوزرات هتتأثر؟

لأ — التعديل في ملفات العرض (الشكل) بس: الرسمة بتقرأ من نفس الداتا المحسوبة أصلًا (نسبة الأوفر لكل خط كانت محسوبة في اللوحة من الأول — احنا بس منعرضنها). قاعدة Neon واليوزرات والشهور مفيش حاجة فيها اتلمست. وملف سير العمل ورقة معلومات بس — مش كود.

ليه مافيش تحديث للنسخة الأوفلاين في الجولة دي؟

عشان اتفقنا النهارده: النسخة الأوفلاين اتقاعدت خلاص — من دلوقتي كل الشغل على الموقع المرفوع (Vercel + Neon) بس. الملف القديم public/Marib_Performance_Studio.html موجود في الريبو كأرشيف ومش هيتحدث في أي جولة بعد كده.

علاقة الجولة دي بالجولة 28 (الأمان)؟

مستقلة تمامًا — R28 بتشتغل في next.config.ts ودي ملفات تانية خالص. عشان كده حطينا الملف بتاعها في نفس الـ ZIP: لو كنت رافعه خلاص مش هيتأثر، ولو لسه — ارفعه مع الجولة دي وتكون كسبت الجولتين في رفعة واحدة.

لو مش عاجباني وعايز أرجّع الدايرة القديمة؟

نفس نظام الرجوع: افتح public/app/app_main.js في GitHub → History → آخر نسخة قبل الجولة → View file → القلم → Commit من غير تعديل. أو قولي أنا وأرجّعهالك.
