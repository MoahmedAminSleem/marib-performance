Key architectural findings:
- The project has TWO parallel auth/database systems (a known R25+ migration in
  progress):
  1. OLD: `src/lib/db.ts` (Prisma + SQLite, models: User/Session/MonthData/AppSetting)

     + `/api/health` + `/api/data` + `/api/storage` + `/api/months`. Cookie name `marib_sess`
     holds a random hex token that's looked up in the Prisma `Session` table.

     for local WASM Postgres) + `src/lib/marib/session.ts` + `src/lib/marib/http.ts`
     + `src/app/api/auth/route.ts` (login GET/POST/DELETE) + all `/api/manpower*`,
     `/api/users*`, `/api/settings`, `/api/audit` routes. Cookie name `marib_sess`
     holds a signed `base64url(payload).base64url(HMAC)` token, verified offline.
